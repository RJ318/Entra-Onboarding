Entra ID New‑Hire Onboarding

A PowerShell module that turns an HR new-hire CSV into Microsoft Entra ID accounts. It validates every row, creates collision-safe usernames, assigns groups and licenses by department, runs a dry run before touching the tenant, and never writes a password to a log.

How it works

  1. ValidateRequired fields, department and license mapping, yyyy-MM-dd dates, manager UPN, 2-letter country.
  2. Planfirst.last@domain, then first.last2, checked against the tenant and earlier rows in the same file.
  3. Review-Offline (no tenant) or -WhatIf (real collision checks), and the plan is saved to CSV.
  4. CreateUser, license, groups, and manager through Graph with least-privilege scopes.
  5. LogCreated, Partial, Failed, or Skipped per row. Temporary passwords are never written to the log.
